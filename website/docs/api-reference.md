# API Reference

The SDK exposes the **same class model** on every platform — the C++ core is wrapped by
[SWIG](https://www.swig.org/) into native Java, Objective-C/Swift and C# bindings, so classes and
methods map 1:1 with a per-platform naming convention.

## Generated reference

| Platform | Reference | Naming |
|---|---|---|
| **Android** (Java/Kotlin) | **[Javadoc →](pathname:///mobile-sdk/api/android/)** | package `com.carto.*`, e.g. `com.carto.ui.MapView` |
| **iOS** (Objective-C/Swift) | **[Jazzy →](pathname:///mobile-sdk/api/ios/)** | `NT` prefix, e.g. `NTMapView` |

:::note Generated on release
The per-language reference is generated by CI on every release and published alongside this site.
If the links above 404, the docs build has not published API output yet — see
[building the docs](/docs/contributing-docs).
:::

## Naming conventions

| Concept | Android | iOS |
|---|---|---|
| Class | `com.carto.ui.MapView` | `NTMapView` |
| Enum value | `CartoBaseMapStyle.CARTO_BASEMAP_STYLE_VOYAGER` | `.CARTO_BASEMAP_STYLE_VOYAGER` |
| Getter | `getZoom()` / property `zoom` | `getZoom()` |
| Vector container | `MapPosVector` | `NTMapPosVector` |

## Key packages

| Package | What's in it |
|---|---|
| `com.carto.core` | `MapPos`, `MapBounds`, `MapVec`, vectors, `Variant`. |
| `com.carto.ui` | `MapView` and click/gesture listeners. |
| `com.carto.layers` | `*TileLayer`, `VectorLayer`, `HillshadeRasterTileLayer`, `CompositeVectorTileLayer`, `CustomRasterTileLayer`. |
| `com.carto.datasources` | `HTTPTileDataSource`, `MBTilesTileDataSource`, `PMTilesTileDataSource`, `ContourTileDataSource`, caches. |
| `com.carto.components` | `Options`, `TerrainOptions`, `Layers`. |
| `com.carto.styles` / `com.carto.vectortiles` | CartoCSS styling and vector-tile decoders. |
| `com.carto.geometry` / `com.carto.vectorelements` | Geometry and on-map elements (markers, lines, polygons, popups). |
| `com.carto.routing` / `com.carto.geocoding` | Valhalla/SGRE routing and (reverse) geocoding. |

## Fork-specific classes

These do not exist in the original CARTO 4.x API — see the [Features](/docs/features/3d-terrain)
section for guides:

- `com.carto.components.TerrainOptions` — [3D terrain](/docs/features/3d-terrain).
- `com.carto.datasources.ContourTileDataSource` — [on-the-fly contours](/docs/features/contours).
- `com.carto.layers.CompositeVectorTileLayer` — [composite layers](/docs/features/composite-vector-tile-layer).
- `com.carto.layers.CustomRasterTileLayer` — [custom raster shaders](/docs/features/custom-raster-shaders).
- `com.carto.datasources.PMTilesTileDataSource` — [PMTiles](/docs/features/pmtiles).
- Extended `com.carto.layers.HillshadeRasterTileLayer` — [hillshade](/docs/features/hillshade).
